# Little Cat Chinese 小猫学中文

A daily Chinese card for my daughter: one new character and one short sentence each day, read in Mom's voice or a built-in voice, with seasonal themes and music.

## Adding Mom's voice
Upload recordings to the `voice` folder with these names:
- `day01-char.m4a`: the character for day 1
- `day01-sentence.m4a`: the sentence for day 1

Any of these formats works: m4a, mp3, wav, webm, aac. The "Save file" button in Mom's corner names the files for you.

## Adding music
Upload songs to the `music` folder, named after a theme:
`halloween`, `thanks`, `christmas`, `winter`, `newyear`, `spring`, `summer`, `autumn`, or `all` (plays for any theme without its own song). Example: `music/christmas.mp3`.
